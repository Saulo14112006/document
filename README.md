# Kanban Local

Um sistema simples de gerenciamento de tarefas (To-Do, Doing, Done) usando Java, CSV e HTML/JS.

## Funcionalidades

- Criar tarefas com título e descrição
- Listar tarefas nas colunas To-Do, Doing e Done
- Mover tarefas entre colunas
- Deletar tarefas
- Persistência local em arquivo `data_tasks.csv`
- Interface web simples (sem frameworks)
